# Simple Remote Desk — Native C++ x64

Нативный C++20-порт рабочей C# v2.11.8.

Цели:
- сохранить SRD3 и совместимость с C# v2.11.8;
- сохранить поведение Host/Viewer;
- не выполнять тяжёлые сетевые/системные операции в UI-потоке;
- переиспользовать криптографические контексты и буферы;
- коалесцировать MouseMove;
- собирать один Windows x64 EXE без .NET Runtime.

Ветка main остаётся эталонной C# v2.11.8. Ветка cpp-port используется только для нативного порта.
