Simple Remote Desk v2.8
=======================

Интерфейс
- Все обычные кнопки унифицированы по высоте, скруглению, шрифту и выравниванию текста.
- Вторичные кнопки получили более заметную синюю рамку/фон и нормальный hover.
- «Подключиться / Изменить / Удалить» теперь размещены в общей адаптивной строке и не должны обрезать текст.
- «Добавить» у найденного компьютера сделана полноценной основной кнопкой.
- Диалог «Добавить/Изменить компьютер» фиксирован; «Добавить/Сохранить» и «Отмена» одинакового размера.
- Host фиксирован по размеру и больше не растягивается/сжимается, поэтому статус и настройки не разъезжаются.
- Увеличена и выровнена кнопка «Новый пароль»; под неё выделена нормальная высота строки.
- Viewer имеет безопасный минимальный размер, но может расширяться; карточки и экран остаются в своих областях.

Удалённые вкладки
- Внутри страницы сеанса больше нет отдельной панели с повторным названием компьютера.
- Статус, звук, «Клавиши», «На весь экран» и «Отключиться» находятся в той же верхней строке, что и вкладки.
- F11 переключает полноэкранный режим, Esc выходит из него.
- В полном экране при подведении курсора к верхнему краю появляется плавающая кнопка выхода.
- Несколько удалённых подключений продолжают работать одновременно в отдельных закрываемых вкладках.

Архитектура и трей
- Основная сборка теперь единая: SimpleRemoteDesk.exe содержит и Host, и Viewer.
- Host постоянно живёт в трее, Viewer является окном того же приложения.
- Обычный запуск открывает Viewer.
- Левый/двойной клик по значку трея открывает Viewer.
- Правый клик -> «Настройки Host» открывает настройки Host.
- Закрытие Viewer не выключает Host.
- «Выход» из трея завершает всё приложение.
- Автозапуск Windows запускает единый EXE с --autostart и не открывает Viewer.

Сборка
- Build-Windows.bat создаёт portable self-contained single-file:
  publish\SimpleRemoteDesk\SimpleRemoteDesk.exe
- На целевом ПК .NET устанавливать не нужно.
- Готовая папка не захламляется сотнями DLL: переносится один EXE.
- .NET runtime всё равно входит внутрь этого EXE, поэтому он не будет весить несколько мегабайт; зато runtime хранится только один раз, а не дублируется отдельно для Host и Viewer.

Сеть
- Сохраняется одновременное обнаружение LAN и Radmin VPN.
- Один Host показывается как один компьютер с несколькими маршрутами.
- LAN имеет приоритет при подключении, Radmin VPN остаётся резервным маршрутом.
