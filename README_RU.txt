Simple Remote Desk v2.11.6 HOVER FIX — ПОЛНЫЕ ИСХОДНИКИ

Основная сборка:
  Build-Windows.bat

Результат:
  publish\SimpleRemoteDesk\SimpleRemoteDesk.exe
  + необходимые DLL/runtime-файлы рядом.

Основной вариант SELF-CONTAINED:
- один процесс Host + Viewer;
- маленький загрузочный EXE;
- .NET 8 НЕ требуется устанавливать на целевой ПК;
- все необходимые runtime DLL публикуются рядом с EXE.

Альтернативная маленькая сборка:
  Build-EXTRA-SMALL-Requires-DotNet8.bat

Она требует установленный .NET 8 Desktop Runtime x64 на целевом компьютере.

Структура исходников:
- SimpleRemoteDesk\  — единая точка запуска одного процесса;
- RemoteHost\        — Host, tray, экран, звук, ввод, discovery;
- RemoteViewer\      — Viewer, карточки, вкладки, удалённые сессии;
- Build-Windows.bat  — основная portable/self-contained сборка.


Версия 2.11:
- Host запускается автоматически при старте приложения.
- Передача файлов через Ctrl+C/Ctrl+V использует дополнительный защищённый TCP-порт: базовый порт + 4 (например 45904).
- Копирование с удалённого ПК: выделите файл в удалённом Проводнике и нажмите Ctrl+C; после получения он окажется в локальном файловом буфере Windows.
- Копирование на удалённый ПК: скопируйте файл локально, вернитесь в удалённый Проводник и нажмите Ctrl+V.
